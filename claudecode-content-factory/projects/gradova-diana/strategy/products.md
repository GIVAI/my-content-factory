**Версия:** 1.0

## Главная цель
**Набор подписчиков** → прогрев → продажа трипваера.

## Воронка
```
Reels (Instagram)  →  кодовое слово в комментах (автоответ)  →  лид-магнит в Telegram @dianagradova
      ↓                                                                      ↓
подписка на профиль                                              прогрев постами в канале
                                                                            ↓
                                                        Трипваер: mini Course на dianagradova.ru
```

## Продукт
| Поле | Значение |
|------|----------|
| **Трипваер** | mini Course — [dianagradova.ru](https://dianagradova.ru) |
| **Задача трипваера** | первая недорогая продажа / вход в клиентскую базу |

## Задачи по лид-магнитам (от Дианы)
1. **Создать НОВЫЕ лид-магниты, которые продают mini Course** (ведут на трипваер).
2. В некоторые **старые лид-магниты добавить ссылку** на mini Course.
3. Старые лид-магниты можно продолжать использовать для **набора аудитории**.

Формат магнитов, которые Диана делает быстро: **подкасты, видео, практики**; возможен **Workbook**.

## Два типа рилс под цель (см. свайп-файл)
- **Лид-рилс** (техника/практика + кодовое слово) → максимум заявок на магнит → в магните продаём mini Course.
- **Подписочные/манифест-рилс** (материнство, ценности, без воронки) → максимум подписок и позиционирования.
