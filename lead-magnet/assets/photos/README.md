# Фотографии

Сюда кладутся исходники — как есть, прямо из телефона или от фотографа.
Сжимать и разворачивать ничего не нужно: при сборке `tools/images.py`
сам выправит поворот по EXIF, переведёт в sRGB и ужмёт длинную сторону
до 2400 px (этого хватает и для экрана, и для печати).

Ссылка в `content/workbook.yaml` — от корня проекта:

```yaml
- type: image
  src: "assets/photos/diana-portrait.jpg"
  height: 62          # высота в мм; ширину займёт по колонке
  position: "center 25%"   # какую часть кадра показывать
```

## Куда фотографии встают

**Портрет рядом с текстом** — страница знакомства:

```yaml
- type: cols
  ratio: [2, 3]        # фото уже, текст шире
  columns:
    - - type: image
        src: "assets/photos/diana-portrait.jpg"
        height: 62
    - - type: lead
        text: "…"
```

**Фоном на тёмной странице** — обложка, шмуцтитул раздела, финал.
Поверх фотографии ложится бордовая заливка, чтобы текст читался:

```yaml
- type: cover
  photo:
    src: "assets/photos/cover.jpg"
    tint: 0.86              # 0 — фото как есть, 1 — сплошной бордовый
    position: "center 30%"
```

`tint` подбирается по фотографии: для светлой хватает 0.8, для
пёстрой лучше 0.9.
