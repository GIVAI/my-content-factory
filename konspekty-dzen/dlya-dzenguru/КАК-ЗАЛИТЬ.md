# Как залить конспекты на Дзен Гуру

Контент LMS живёт в Supabase и отдаётся в рантайме. **Деплой не нужен и
запрещён** — по правилу проекта (`CLAUDE.md`, DZEN WAY, шаг 3).

Штатный путь — `scripts/lms-content.py`. Операция занимает секунды.

---

## Команды

Выполнять из корня `dzen-guru`, файл `konspekty-efirov.html` положить рядом.

```bash
# 1. Найти модуль курса «Старт на Дзен» (это course_id = 2)
python3 scripts/lms-content.py modules --course 2

# 2. Создать урок в нужном модуле (подставьте его id вместо N)
python3 scripts/lms-content.py create-lesson \
    --module N \
    --slug konspekty-efirov \
    --title "Конспекты живых эфиров" \
    --file konspekty-efirov.html
```

Сначала то же самое на stage — флаг `--stage`:

```bash
python3 scripts/lms-content.py --stage create-lesson --module N \
    --slug konspekty-efirov --title "Конспекты живых эфиров" \
    --file konspekty-efirov.html
```

**Если урок уже создан и нужно обновить текст:**

```bash
python3 scripts/lms-content.py set-content <lesson_id> --file konspekty-efirov.html
```

---

## Почему файл выглядит «голым»

В нём нет ни тега `<style>`, ни атрибутов `style` — намеренно.

Оба вырезаются санитайзером на бэкенде (`_ALLOWED_TAGS` / `_ALLOWED_ATTRS`
в `html_sanitizer.py`) и повторно на фронте (`FORBID_TAGS` в `sanitize-html.ts`).
Причём на фронте стоит `KEEP_CONTENT: true` — то есть если бы `<style>`
остался, CSS вывалился бы **видимым текстом** прямо в урок.

Оформление даёт сам контейнер урока:

```
prose prose-neutral max-w-none dark:prose-invert prose-headings:font-heading …
```

Поэтому конспект подхватит типографику платформы и тёмную тему сам,
а не будет выглядеть чужеродной вставкой.

## Что проверено до отправки

Файл прогнан через **настоящий** `sanitize_blog_html` из этого репозитория:

| Элемент | До | После |
|---------|-----|-------|
| h2 (разделы) | 11 | 11 |
| h3 | 98 | 98 |
| h4 | 88 | 88 |
| Таблицы | 32 | 32 |
| Цитаты | 66 | 66 |
| Блоки `pre` | 29 | 29 |
| Списки ul / ol | 28 / 16 | 28 / 16 |
| Пункты списков | 203 | 203 |
| Ссылки | 20 | 20 |

**Ни один элемент не потерян.** Все 11 якорей (`#soderzhanie`,
`#konspekt-01` … `#konspekt-10`) сохранились — оглавление кликается.

## Что внутри

Один урок: вступление, оглавление на 10 пунктов, десять конспектов подряд,
после каждого — возврат к оглавлению.

01 Подготовка · 02 Запуск канала · 03 Буст и разгон · 04 Автоматизация ·
05 Разбор каналов · 06 Стелы · 07 Стратегия старта · 08 Диагностика ·
09 Большой разгон · 10 Шпаргалка

Дат в названиях нет. Цен и тарифов нет. Раздел про стелы включён и сверен
с двумя последними эфирами.

---

## Доступ

Отдельно ничего настраивать не нужно: урок внутри курса, его видят те,
у кого есть зачисление на «Старт на Дзен». Читатели блога и подписчики
сервиса без зачисления туда не попадают.
