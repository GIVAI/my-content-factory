# 📌 Шпаргалка: все цифры и правила на одной странице

> Всё, что стоит держать перед глазами. Разъяснения — в соответствующих конспектах.

---

## 🎚 Уровни тестовых показов

```
1-й уровень  →  ~250 показов на публикацию
2-й уровень  →  ~1 000 показов
3-й уровень  →  ~10 000 показов  →  ЗДЕСЬ включаются рекомендации
```

Новому каналу доступно **15%** ленты. Основная лента + рекомендации = **85%** трафика
платформы.

**Рекомендации — следствие расширения показов, а не причина роста.**

---

## 🔁 Как работает алгоритм сейчас

```
Публикация → тестовые показы 200–500
   → пришли подписчики? ─ нет → стоп (возврат несколько раз за 16 дней)
   → да → ~2 000 показов
   → снова подписчики? ─ да → ЛЕНТА + РЕКОМЕНДАЦИИ (85%)
```

Главная метрика — **подписчики после дочитывания**, а не лайки и комментарии.

## ⭐ Стелы: правила

- **Максимум 1 стела на публикацию в день**
- Ставить **8:00–17:00 МСК**. После 21:00 не отрабатывает
- Отработка **на следующий день** (до 10:00 → с 10:00; до 17:00 → с 17:00)
- Стартовый буст: **10 публикаций × 10 стел**
- Рабочая норма: **20–30 в день**, минимум 15–20
- Работают на публикациях за **последний месяц** (было — 3 месяца)
- Лучше всего отрабатывают публикации **за последние 5 дней**
- Ставить лучше **с живых каналов** — с нулевых хуже
- **Дочитывание перед постановкой** повышает срабатывание с ~70% до 80–90%
- Стабильность важнее объёма

## 🗓 Календарь месяца

```
ПОСЛЕДНЯЯ НЕДЕЛЯ  →  ничего не запускаем. Чистка. Планируем следующий месяц
1-Я НЕДЕЛЯ        →  БУСТ или РАЗГОН (что-то одно)
2–3-Я НЕДЕЛИ      →  работаем на найденной норме, ставим отложку
```

### Буст
```
ПН–ЧТ  →  ×2–3 публикаций от обычного
ПТ–ВС  →  планомерное снижение по одной в день
```
Старт **строго с понедельника**. Не работает на 2–3 день → раньше начинайте снижаться.

### Разгон
```
ЧТ  →  0 публикаций. ЧИСТКА + ПЕРЕЛИНКОВКА
ПТ  →  1 публикация
СБ  →  1 публикация
ВС  →  1 публикация  ← ДОБОР рекламной сети
```
Перед разгоном чистка **обязательна**. До разгона должен быть хотя бы один буст.
Срабатывает в **7 случаях из 10**, даёт **×2–×3**.

### Чистка
- Основной способ — **по комментариям**, 4 категории, сносим публикации с явным негативом
- Отлетает **10–20%** публикаций
- Не трогаем: вечнозелёные, SEO-статьи из поиска, низкий CTR (правим заголовок),
  низкое дочитывание (докручиваем)
- Даёт **+30% к конверсии в подписку**
- Имеет смысл **от 100 публикаций** на канале

## ✍️ Правила текста

**Дзен — это сторителлинг.** Не SEO-структура.

| ✅ Делаем | ❌ Не делаем |
|-----------|-------------|
| От первого лица, автор виден | Подзаголовки-кластеры «что такое X → как работает X» |
| Мнение сквозь весь текст | Отдельный блок «моя точка зрения» |
| Мягкий вопрос в конце, вплетённый в текст | Отдельный жирный блок «подпишись, прокомментируй» |
| Абзацы нормальной длины | Рваные абзацы (режут дочитывание на 15%) |
| Один подзаголовок так, чтобы не собралось оглавление | Кавычки и ёлочки в заголовках |
| Реалистичные картинки, атмосферные обложки | Фотосток, глянец |
| Обложка коннектится с заголовком | Ссылки на исследования «для алгоритма» |
| Заголовок сильный **словами** | Дефисы, длинные тире, заезженные фразы |

**SEO и рекомендации — выбор одного из двух.** На Дзене SEO живёт только в заголовках.

**Сильный CTA:** не «что вы думаете?», а **«правильно я поступила или нет?»** —
образуются два лагеря. Даёт ×2 к подпискам.

**Тон концовки определяет тон комментариев.** Заканчивайте на доброй ноте.

## 🔧 Система: правила докрутки

**Три шага ручной докрутки:**
1. «Изучи систему полностью, каждый файл от начала до конца»
2. «Определи все взаимосвязи и **выпиши** их» + «Найди дубли внутри файлов и между ними»
3. «Распиши очень коротким списком, как ты действуешь поэтапно»

**Закрывает ~80% необходимого.**

**Железные правила:**
- Каждый параметр указывается **один раз**. Три повтора = модель путается
- Нейросеть **не умеет считать символы** — она считает токены и на русском занижает
  почти вдвое. Нужен Python-скрипт подсчёта в системе
- **Чтобы модель что-то учла, она должна это ВЫПИСАТЬ.** «Я посмотрел и точно говорю» —
  не факт
- **Сюжет и текст должны быть в одном чате.** Принесённый из другого чата сюжет
  отрабатывается хуже. Обходной путь: «сначала выпиши весь сюжет, потом пиши по нему»
- **Не просите «допиши сцену, если не хватает символов»** — модель вставит случайную
  сцену посреди сюжета
- Масштаб: **50–100 тем → проверить → масштабировать.** Не 900 сразу
- Рабочая система проходит **15–30 докруток**. Это норма

**Докрутка по комментариям** — самый честный способ: берёте содержательный негативный
комментарий, закидываете вместе с системой и спрашиваете, что поправить.

## 🎯 Контент-план: правило третей

```
1/3  →  сгенерированный из словаря ниши
1/3  →  свои темы через триггеры подписки
1/3  →  живые темы из рекомендательных блоков основной ленты
```

**На старте берём низкоконкурентные сущности**, не топовые.

**Как попасть в 85% ленты:** открыть публикацию в своей теме → спуститься ниже
комментариев → там блок рекомендованных → брать оттуда свежие темы (2–5 месяцев).

---

## ⚙️ Автоматизация

- Генерация **пачками от 10 тем** — выгоднее
- Загружать **утром, 8:00–11:00** — в 3–4 раза быстрее
- Полный цикл на статью: 5–10 итераций, 20–30 минут
- Для массовой автопубликации нужны **мобильные прокси** (обычные ложатся под защиту)

## 💀 Когда канал реально стоит бросить

**Единственный настоящий критерий:** трафик из ленты **меньше 4–5%** + подписчики
не реагируют (1–2 человека из тысячи заходят на новые публикации).

**Отсутствие рекомендаций — НЕ причина бросать канал.**
