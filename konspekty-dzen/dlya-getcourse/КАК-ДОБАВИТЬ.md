# Как добавить конспекты на GetCourse

Эта папка — версия конспектов под вставку в уроки платформы.
Доступ к ним получат **только залогиненные ученики с открытым тренингом** —
это единственный способ реально ограничить круг читателей.

---

## Порядок действий

1. Тренинг «Старт на Дзен» → раздел **«Прямые включения»**
2. Создать урок. Название — из таблицы ниже, **без даты**
3. В редакторе урока добавить блок **«Код»** (или «HTML» — в разных
   версиях редактора называется по-разному)
4. Открыть нужный `.html` файл из этой папки, скопировать **всё содержимое
   целиком** — вместе с `<style>` в самом начале — и вставить в блок
5. Сохранить

Файлы самодостаточны: шрифты системные, ничего снаружи не подгружается,
все стили заперты внутри `.kdz` и на оформление платформы не влияют.
Порядок уроков — по номерам файлов, это выстроенный путь от подготовки
канала до разгона.

## ⚠️ Отдельно про конспект 06 «Стелы»

На эфире была прямая просьба не распространять эту информацию за пределы
обучения — и уже был случай, когда за сутки она ушла к трём посторонним.

Варианты, как поступить:

- **Положить как обычный урок** — доступ есть у всех учеников тренинга.
  Проще всего, но пересказать содержимое дальше никто не мешает
- **Открыть только основной группе** — тем, кто уже с монетизацией.
  На GetCourse это делается ограничением доступа к отдельному уроку
- **Не выкладывать на платформу вовсе**, оставить только в закрытом чате,
  как и был исходный эфир

Решение за вами — я оставил конспект в общем наборе с предупреждением внутри.

## Если понадобится обновить

Исходники — в markdown, папкой выше (`konspekty-dzen/*.md`).
Правите markdown → пересобираете HTML → заменяете содержимое блока в уроке.
Так текст остаётся в одном месте, а не расползается по копиям.
